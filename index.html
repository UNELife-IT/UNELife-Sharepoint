UNE LIFE SharePoint User Guide

Everything you need to work in the new SharePoint structure

Go-live: Monday, 2 November 2026 Audience: All UNE LIFE staff Support: IT Support (Joshua Webel)

1. Overview

From 2 November 2026, UNE LIFE files will be stored in a new, standardised SharePoint structure. The aim is to make files easier to find, keep naming consistent, and make access to sensitive content more secure.

What's changing

  • A new folder structure organised by division/team
  • Consistent naming conventions
  • Access based on role, so you will see only what is relevant to you
  • Files will be migrated by IT and nominated staff before go-live

What's not changing

  • You still sign in with your UNE LIFE corporate account
  • Office apps (Word, Excel, PowerPoint) work as they always have

2. Accessing SharePoint

  1. Open a browser (Edge or Chrome recommended).
  2. Go to the SharePoint site link supplied by IT.
  3. Sign in with your UNE LIFE corporate email and password, then complete MFA if prompted.
  4. Select your team or division site from the navigation menu.
Tip: Click the star (Follow) icon on any site, or select Add shortcut to OneDrive, to find it quickly later.

Can't see a folder you need? Don't try to work around it. Submit an access request to IT, with approval from your manager.

Best practices

  • Keep folder depth to 6 levels or fewer
  • Avoid creating new top-level folders. Ask IT first.
  • Use the search bar at the top of the page. It searches file names and content you have access to.

4. Naming Conventions

Consistent names make search and sorting reliable.

  • Use clear, descriptive names
  • Avoid double spaces, typos, and inconsistent capitalisation
  • Avoid special characters: ~ " # % & * : < > ? / \ { | }
  • Put dates in YYYY-MM-DD format
  • Use version labels where needed (e.g., v1, v2, FINAL)

5. Everyday Tasks

Upload files

  1. Open the target folder.
  2. Select Upload, then Files or Folder, or drag and drop from File Explorer.

Create a new file or folder

Select New, then choose a folder or Office document type.

Edit and collaborate

  • Open files in the browser or desktop app.
  • Multiple people can edit at the same time. Look for coloured cursors showing who is editing.
  • Use Comments and @mentions to give feedback instead of emailing copies.

Share a file

  1. Select the file and click Share.
  2. Prefer People with existing access or Specific people.
  3. Do not use "Anyone with the link" for internal or sensitive documents.
  4. Add a message and select Send.

Sync to your computer

Select Sync in the library toolbar. The folder will then appear in File Explorer under your UNE LIFE account.

Restore a deleted or earlier version

  • Deleted file: go to the Recycle bin (left menu) and select Restore.
  • Earlier version: right-click the file, select Version history, then choose Restore.

6. Do's and Don'ts

Do

  • Save files directly to SharePoint, not local drives or USB
  • Check you are in the correct folder before uploading
  • Share links instead of attaching copies
  • Report anything that looks misplaced or inaccessible

Don't

  • Store passwords or sensitive personal data in open folders
  • Create duplicate copies of the same document
  • Move or rename large folders without checking with IT
  • Share files externally without approval

8. Getting Help

When contacting IT, include:

  • Your name and division
  • The site/folder name or link
  • A screenshot of any error message
  • What you were trying to do

9. Quick Reference

  • Search: use the bar at the top of any SharePoint page
  • Follow a site: click the star
  • Sync a library: use the Sync button
  • Share: use specific people, not "Anyone"
  • Naming: YYYY-MM-DD Description vX
